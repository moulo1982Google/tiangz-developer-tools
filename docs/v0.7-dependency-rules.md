# 0.7 依赖方向统一

2026-09-26 实施前冻结。插件保持 0.15.2，依赖规则独立版本 1；不把 worktree 名作为插件版本。

唯一 AST 规则维护在 project-core/dependencyRules.ts，主工程 CLI/LSP、TiangZ 边界命令、模块 CLI/Host worker 复用。接受调用方 TypeScript API，静态 import/export、动态 import 字面量、import type 表达式、import-equals 和相对类型增补均检查；注释和普通文本不当导入。无法确定的动态 import 给 warning，不能称作已证明安全。任意反射、用户包装器和业务 require 函数不属于本项静态证明范围。

Model 通过 Stable Core public 入口；仅保留已批准的精确启动/聚合文件例外，不对整个 main/bench/generated 目录放行。Core 不依赖 Model/Hotfix，Hotfix 使用 Stable Model 或自己的 Hotfix 层。保留既有 Generated/Bootstrap、Generated/Model 与 Generated/Hotfix 方向。宿主 Program 另提供实际导入目标，配置别名不能掩盖相反依赖。

模块由当前宿主传入清单的 Model/Hotfix roots、Stable 入口和已声明公共 API resolver。跨模块公共 API 必须有直接依赖/版本证据；相对路径不得跨出自身声明层。生成协议内部 ABI 例外限定到声明的 serverOutput、正式生成器标记和四个精确 Core ABI 文件；System 类型增补限定到正式生成的 System.d.ts 和领域原声明。生成指纹/锁仍由宿主负责，文件标记不是安全认证。

首轮 `dist/v0.7-dependency-rules-first.log` 5 项中 4 项失败，实际漏检 Model 内部 Core、Core 的 Model 别名、type-only/import-equals 和精确启动例外。禁止把错误降为 warning、忽略所有 Generated 或恢复旧错误白名单；修复后执行正反例、TS 5/6 对照、主工程和模块 CLI/实际安装 LSP 及宿主矩阵。新共享入口缺失时明确报告依赖未就绪，不静默回退旧规则。

后续实际 CLI/LSP 发现直接比较 Windows 反斜杠与 TS 正斜杠会误报 Stable 身份；改为平台路径身份比较，保留大小写对照。另一个真实文件反例证明，Program checked 不能全局禁用语法回退，否则 tsconfig 排除文件会漏检；现在仅对实际已检查文件去重，不更改用户配置。首次失败分别保留 `dist/v0.7-dependency-check-first.log` 与 `dist/v0.7-dependency-excluded-first.log`。

最终 13 项依赖专项（含实际 TS 5/6）通过，`dist/v0.7-dependency-final-targeted.log`；完整插件检查通过，`dist/v0.7-dependency-check-final.log`。实际安装验证使用独立 extensions/user-data 目录，并从安装位置运行 Language Server；最终归档、npm 候选、标准库与安装内容的身份及宿主矩阵证据记录在 TiangZ 的 `docs/design/v0.7-dependency-rules.md`。发布依赖、版本冻结和用户日常客户端安装仍分开处理。
